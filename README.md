# 🎙️ Nexus — Автономный голосовой ассистент для Android

**Nexus** - это полностью автономный голосовой ассистент для Android, работающий на базе локальных нейросетей. Его главная задача - предоставить пользователю естественный голосовой интерфейс для управления смартфоном без обращения к облачным серверам. Вся обработка речи происходит **on-device**, что гарантирует высокую скорость отклика, работу без интернета и абсолютную приватность данных.

## ✨ Ключевые особенности

*   **100% On-Device:** Распознавание речи и детекция активности работают локально.
*   **Управление приложениями:** Открытие приложений по голосовой команде (например, « Нексус,открой Телеграм»).
*   **Умный поиск:** Устойчивость к ошибкам распознавания речи и поддержка синонимов для названий приложений.
*   **Фоновая работа:** Постоянное прослушивание через `Foreground Service` с индикацией в шторке уведомлений.
*   **Авторизация:** Интеграция с Yandex Auth SDK.

## 🛠️ Стек технологий

*   **Язык:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Архитектура:** MVVM, Clean Architecture (Coroutines, StateFlow)
*   **AI/ML:** Sherpa-ONNX (Silero VAD + Zipformer ASR)
*   **Системные API:** AudioRecord, Foreground Service
